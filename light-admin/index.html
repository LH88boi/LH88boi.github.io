用 GitHub 令牌登录

只需设置一次，令牌只存在你自己的浏览器里。与天网写作共用同一个令牌。

第一次使用，先生成一个令牌：
  1. 打开 github.com/settings/tokens/new
  2. Note 填 diary，Expiration 选 No expiration
  3. 勾选 repo（整个大类），点 Generate token
  4. 复制那串字符，粘贴到下面
