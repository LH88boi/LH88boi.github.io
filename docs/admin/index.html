用 GitHub 令牌登录

只需设置一次，之后打开这个页面就是登录状态。令牌只存在你自己的浏览器里。

第一次使用，先生成一个令牌：
  1. 打开 github.com/settings/tokens/new
  2. Note 随便填，比如 diary
  3. Expiration 选 No expiration
  4. 勾选 repo（整个大类，展开后第一项）
  5. 拉到底点 Generate token，复制那串字符
粘贴后点登录。令牌不会上传到任何第三方，只用于读写你的仓库。
